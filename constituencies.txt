# constituencies.txt
#
# Single source of truth for which constituencies exist, used by BOTH:
#   - streamlit_app.py   (builds the Home page + one page per row that is
#                          both uncommented AND enabled=True)
#   - extract_pdfs.py    (extracts zips for rows with extract_needed=True,
#                          regardless of the enabled column)
#
# Two independent ways to hide a constituency:
#   - Comment a line out with a leading #  -> skipped EVERYWHERE (app AND
#     extraction). Use this once a constituency is fully retired/unused.
#   - Set enabled to False (line stays uncommented) -> extract_pdfs.py can
#     still process it, build_database.py still writes its .db file, but
#     it stays OFF the public Streamlit Home page/nav until you flip it to
#     True. Use this while you're still testing a newly-added constituency.
#
# Columns (pipe-separated):
#   constituency   -> must exactly match the "AC: <num>-<name>" text parsed
#                      from that constituency's PDFs. build_database.py
#                      prints this exact value after each rebuild -- copy it
#                      from there rather than retyping it, to avoid typos.
#   db_filename    -> the per-constituency SQLite file build_database.py
#                      writes (e.g. data_175.db) -- this is what the deployed
#                      Streamlit app actually reads.
#   zip_path       -> (local machine only, ignored by the deployed app)
#                      path to that constituency's source zip. Can be
#                      RELATIVE to this project folder, e.g.
#                      pdfs\AC 175 Bommanahalli-20260808T110311Z-1-001.zip
#   dest_path      -> (local machine only, ignored by the deployed app)
#                      folder to extract that zip's PDFs into. Also can be
#                      relative, e.g. pdfs\175-Bommanahalli
#   extract_needed -> True/False -- only rows marked True get extracted the
#                      next time you run extract_pdfs.py.
#   enabled        -> True/False -- only rows marked True show up in the
#                      Streamlit app (Home page + its own page/URL).
#
